**Windows:** run `KaradagBeat-*-Setup.exe`. It isn't code-signed, so Windows may warn about an unknown publisher: click More info > Run anyway.

**macOS:** open `KaradagBeat-*-macOS.pkg`. It isn't notarized, so the first time macOS blocks it: open System Settings > Privacy & Security, click Open Anyway and open the package again.

Then rescan plugins in your DAW. Works in any VST3 host (Ableton Live, FL Studio, Cubase, Studio One, Reaper, Bitwig) and, on macOS, in Logic Pro and GarageBand as an Audio Unit.

`KaradagBeat-*-Windows-VST3.zip` is the Windows plugin on its own, for installing by hand: copy `Karadag Beat.vst3` into `C:\Program Files\Common Files\VST3`.
